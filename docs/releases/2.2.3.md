# NetMonitor 2.2.3 — release notes (iOS/widget build 24 / macOS 1795306090)

2.2.3 is a patch on 2.2.2 (iOS 23 / macOS 1795258945, live 2026-11-21). It turns off UniFi device lookup on both apps: scans no longer read the UniFi gateway's device list, Settings can no longer add a UniFi API key, and a key saved earlier is never read or sent. Settings shows the lookup as temporarily unavailable and offers to remove a saved key. Everything else in discovery is unchanged.

## App Store "What's New" (user-facing)

### NetMonitor (iOS)
- Security improvements.
- UniFi device lookup is temporarily unavailable. A UniFi API key you saved earlier isn't used, and you can remove it in Settings.

### NetMonitor Pro (macOS)
- Security improvements.
- UniFi device lookup is temporarily unavailable. A UniFi API key you saved earlier isn't used, and you can remove it in Settings › Network.

## What changes for users
- Devices that only UniFi's list identified (UniFi switches and access points on a fixed address, some clients) lose the maker and model it gave them until the lookup returns. Names, Bonjour, UPnP and hostname-based makers are unaffected.
