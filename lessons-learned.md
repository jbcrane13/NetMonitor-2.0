# Lessons learned — NetMonitor-2.0

Project-specific notes for agents. Global lessons live in `~/.claude/lessons-learned.md`; testing-specific history is in `docs/TESTING-LESSONS-LEARNED.md`.

## 2026-09-18 — Architecture-deepening epic #273 (S1–S7)

- **Run the macOS unit target on `blakes-mac-mini-2` with per-test timeouts.** `xcodebuild test … -only-testing:NetMonitor-macOSTests` without `-test-timeouts-enabled YES -default-test-execution-time-allowance 90 -maximum-test-execution-time-allowance 120` hangs indefinitely in the live-Bonjour suites (test host idle for 30+ minutes). With the flags, ten tests fail by time limit or assertion on `main` regardless of the change under test — see #287 for the list. Compare a branch's failure list against `main`'s before treating any of them as a regression.
- **The node has no xcodegen or Homebrew on its non-interactive PATH.** It builds from the committed `NetMonitor-2.0.xcodeproj/project.pbxproj`, so any change that adds a file to an app or test target must run `xcodegen generate` locally and commit the regenerated pbxproj.
- **The node's LAN interface is en1, not en0.** `NetworkUtilities.detectLocalIPAddress/detectLocalIPv4Network/detectDefaultGateway` default to `"en0"`; code that scans "the local network" without an active `NetworkProfile` must probe interfaces (the coordinator now does, `DeviceDiscoveryCoordinator.selectFallbackInterface`). A live-scan gate on the node that assumes en0 reports zero devices.
- **Live-scan gate for discovery changes:** `TEST_RUNNER_NETMONITOR_LIVE_SCAN=1 xcodebuild test … -only-testing:NetMonitor-macOSTests/DeviceDiscoveryCoordinatorLiveScanTests` prints `LIVE_SCAN devices=<n> gateway=<found|missing>`; baseline recorded 2026-09-18 on the pre-S6 coordinator was `devices=0 gateway=missing`, post-S6 `devices=1 gateway=found`.
- **Known environmental package-test failures** (do not "fix" in unrelated PRs): NetworkScanKit `ScanPipelineRealIntegrationTests` "finds at least 1 device" needs a live LAN; NetMonitorCore `SSLCertificateContractTests` "days between two known dates" adds 60×86400 s to `now` and crosses a DST change for part of each year.
- **CI SwiftLint/SwiftFormat/coverage jobs fail on `main` already (#264)**; they are not merge blockers for otherwise-green PRs, but lint your changed files locally with `--baseline .swiftlint_baseline.json`.
- **Sandboxed macOS app cannot open the ICMP socket** `ICMPLatencyPhase` needs (no raw-socket entitlement), so `DeviceDiscoveryCoordinator.measureDeviceLatencies` (shell `/sbin/ping`) remains the macOS latency source of record (ADR-macOS-003) even though the scan now runs through `ScanEngine`.
- **Worker orchestration that worked:** Sonnet subagents with `isolation: worktree`, branches cut from `origin/main` (not the orchestrator's local `main`), ownership acknowledgement comment before editing, checkpoint comments every ~10 minutes, orchestrator reviews each PR (Standards + Spec) and runs the node tests serially before merging. Frontier sizes of 4 → 2 → 1 kept file ownership disjoint.
