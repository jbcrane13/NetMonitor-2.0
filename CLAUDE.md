# CLAUDE.md

The shared rules for this repo are in `AGENTS.md`, which Claude Code loads through the agents-md setting. This file holds only what is specific to Claude Code; add shared rules to `AGENTS.md`, never here.

That loading comes from the user-level `cc-plugin-agents-md` setting (`instructionFiles: claude-md-and-agents-md`) in `~/.claude/settings.json`. On a host without it, read `AGENTS.md` yourself before starting work.
